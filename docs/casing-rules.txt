#
# Format: canonical form | comma-separated wrong forms | comma-separated exempt forms
#
# Lines starting with # are comments. Blank lines are ignored.
# Matching is performed on prose text (fenced code blocks are skipped).
# Inline code spans are checked unless the token matches an exempt form.
