---
name: memforge-memory
description: Use when you need to search, compile, or save local project memories through memforge.
---

Use the `memforge` MCP server tools when available:

- `search_memory` for targeted memory retrieval during coding.
- `compile_context` or `get_project_context` before starting a task.
- `save_memory` only for human-confirmed memories.

Memories are local-first. Do not ask memforge to scan the repository automatically, and do not persist candidates unless the user has approved them.
